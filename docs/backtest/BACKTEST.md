# TRU POWER three-season backtest

Generated by `node tools/metrics.js` from the output of `tools/reproduce.sh`. Every number below is computed by that script; see the definitions in its header.

Scope: official-event qualification matches with a winner (ties excluded). Each match is predicted using only matches played before it; season priors use only events that finished before the event started. **2026 is the season the settings were tuned on; 2025 and 2024 are blind tests with frozen settings.** The comparison model is a re-implementation of Statbotics EPA from its open-source code (its API was unavailable).
